# PIRL League: homepage design preview

Design preview prepared by Premier Code Inc. for the Professional Indian Relay League (Ringling, OK).

- Preview: https://pirl.premiercodeinc.com/
- Version 1: `/`
- Option A, The Exchange: `/option-a/`
- Option B, The Race Program: `/option-b/`
- Static HTML/CSS/JS with no build step. Each version has its own `index.html`, `styles.css` and `main.js`, sharing `assets/`.
- Kept out of search engines on purpose (`noindex` meta + `robots.txt`) until launch.
- Forms are previews and send nothing. Wire them up with reCAPTCHA v3 alongside the honeypot.
